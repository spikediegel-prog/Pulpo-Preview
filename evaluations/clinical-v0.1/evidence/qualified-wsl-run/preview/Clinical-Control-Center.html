VM & diagnostics

Selected setup profile: esxi. This is configuration, not detected hypervisor or qualification.

ESXi and Hyper-V: use a disposable Ubuntu guest, isolated virtual network, local console, synthetic data and no production credentials. Keep state on the guest filesystem. WSL: keep the lab on the Linux filesystem; distinguish host, guest and exported evidence context.

VM snapshot rollback can restore spent authority. Never resume execution from an old snapshot as if its audit chain proves freshness. Restore only for a new disposable test run; no production recovery claim.

This report is a static snapshot. Reopening does not refresh it. Rerun the separate test runner to a new directory for new evidence. Native Control Center provides the observer view; no controls here execute or approve actions.
